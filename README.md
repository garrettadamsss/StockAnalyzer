# StockAnalyzer 

Web app to execute and visualize my custom stock investment analysis. The custom stock investment analysis is built around the book, _The New Money Strategy: The Modern Guide to Rational, Long-Term Investing_ by **Brandon van der Kolk**, 
which synthesizes **Warren Buffet**'s investing approach. Stock investing is not only a hobby of mine but an integral component of my life as I seek financial
freedom. **StockAnalyzer** makes my investment decisions precise, consistent, and streamlined. 

## Features
Uses up to date and wealth of financial data both qualitative and quantitive.
Clearly structures analysis results into well defined sections. 
1. Executive Summary
2. Understand the business
3. Checking for a moat
4. Valuation
5. Verdict
Provide charts and diagrams to visualize financial quantive data.
